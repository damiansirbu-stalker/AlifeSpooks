# AlifeSpooks source licensing

Every source AlifeSpooks uses, and the basis for using it: the author granted permission, the addon's license permits it, or it is GSC-original game audio. The readme Credits section derives from this record.

## Permission

The authors gave permission for my S.T.A.L.K.E.R. mods, each grant recorded below with where and when it was given (Discord handle or moddb PM, and date).
Freely licensed sources (Public Domain, Creative Commons) and GSC-original audio need no grant.
